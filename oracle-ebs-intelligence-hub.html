⚡ Oracle SQL Performance Advisor

                    
Paste a slow Oracle EBS query. The advisor scans it for known performance patterns and shows what to fix, plus a rewritten version.

                    
How to use: 1) Pick the module and paste your SQL, or click Load Sample SQL. 2) Click Analyse & Optimise. 3) Read Issues, then Recommendations, then copy the Optimised SQL.
                        The cost figures are indicative scores from rule-based checks, not Oracle EXPLAIN PLAN results. Confirm with EXPLAIN PLAN in your database.

🔍 Oracle EBS SQL Code Review

                    
Paste your SQL for a quality check against 27 Oracle EBS rules. You get a score out of 100 and a before/after fix for each finding.

                    
How the score works: it starts at 100. Each Critical finding (wrong results or a major slowdown) takes off 20, each Major 10, each Minor 5. Info and Good items do not change the score.

✨ Oracle SQL Code Formatter

                    
Paste Oracle SQL. The formatter puts each column, table and JOIN on its own line, applies your keyword case and indent, and keeps sub-queries together. It works best on SELECT statements; PL/SQL blocks get basic line breaks only.

                    
How to use: 1) Paste SQL or click Load Sample. 2) Choose indent and keyword case. 3) Click Format SQL, then Copy, or send the result to the Performance Advisor or Code Review.

      1
      
            
      
              Load your data — drop an Excel/CSV file or paste a SELECT query in DB mode.

              text, number, date, bool, or mixed.
            
      
          
      
          
      
            
      2
      
            
      
              Choose a target EBS Report — pick from the dropdown (e.g. AP Invoice Register)

              format dates as YYYY-MM-DD, format numbers with 2 decimal places, or Title Case.

              Preview & Push — the mapped data shows in a paginated grid with
              data profiling (nulls %, unique count, samples). Click 🚀 Push to Reports Tab
              to inject your data into the EBS Reports tab where you can filter, chart and export it.
            
      
          
      
        
      

        
        
      
          
      🔌 Connecting to a Real Oracle DB
      
          
      
            
      
              
      🔒 Simulated Mode (current)
      
              
      No real DB needed. The app recognises EBS table names in your SQL
                (ap_invoices_all, gl_je_headers, etc.) and returns
                matching demo data — perfect for testing, demos, and training.
      
            
      
            
      
              
      🔌 Live DB Mode (with proxy)
      
              
      Switch to Live DB in the DB Query panel. Enter your Oracle host,
                port, SID and credentials. A lightweight backend proxy
                (Node.js or Python) relays your SELECT query to the DB via
                JDBC or cx_Oracle and returns results as JSON.
                The app then loads them exactly like an Excel import.
      
              
      
POST http://localhost:3001/query
      
{ "sql": "SELECT ...", "host": "...", "sid": "...", "user": "...", "pass": "..." }
      
→ { "columns": [...], "rows": [[...], ...] }
              
      
            
      
            
      
              
      📊 Excel / CSV (recommended)
      
              
      Run your Oracle report/query in SQL*Plus, Toad, or SQL Developer.
                Export to .xlsx or .csv.
                Drop it here — headers auto-detected, up to 5,000 rows,
                multi-sheet workbooks supported. No DB credentials needed in the browser.
